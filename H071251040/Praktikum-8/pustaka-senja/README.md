# Pustaka Senja

Aplikasi multi-halaman ruang baca komunitas — Tugas Praktikum 8 (Next.js App Router + Tailwind CSS).

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000

## Halaman

| URL | Isi |
| --- | --- |
| `/` | Beranda: Hero + statistik koleksi |
| `/katalog` | Katalog buku, filter kategori, tombol simpan |
| `/katalog/[id]` | Detail buku dinamis |
| `/usulan` | Formulir usulan buku |
